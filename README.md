# Brainrodle

Zgadywanka słowna z Gen Z slangiem. Masz 6 prób na odgadnięcie słowa dnia.

## Tryby gry

- **Dzienny** — jedno słowo dziennie, wspólne dla wszystkich graczy. Reset o północy czasu warszawskiego.
- **Nieograniczony** — losowe słowa, grasz ile chcesz.

## Jak grać

1. Wpisz słowo (musi być na liście)
2. Po każdym zgadywaniu kafelki pokazują:
   - 🟩 zielony — litera jest na miejscu
   - 🟨 żółty — litera jest w słowie, ale nie na tym miejscu
   - ⬛ szary — litery nie ma w słowie
3. Masz 6 prób. Powodzenia.

## Co w środku

```
index.html      # strona gry
script.js       # logika
styles.css      # wygląd (neon, glitch, ciemny motyw)
unlimited.html  # tryb nieograniczony
unlimited.js    # logika dla unlimited
```

Zero zależności zewnętrznych. Żadnego frameworka, żadnego backendu, żadnego API.
Wszystko w jednym folderze, otwierasz i działa.
